# CSS3 Local Community Portal

This project is developed using HTML5, CSS3, and JavaScript.

## Features
- Responsive Design
- Event Registration Form
- Community Event Gallery
- Event Feedback Section
- Geolocation Support
- Video Integration
- CSS3 Animations and Hover Effects
- Media Queries
- Multi-column Layout
- Local Storage

## Technologies Used
- HTML5
- CSS3
- JavaScript
